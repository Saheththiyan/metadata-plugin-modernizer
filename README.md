# Jenkins Plugin Modernizer – Metadata Repository

This repository stores the modernization metadata generated by the [plugin-modernizer-tool](https://github.com/jenkins-infra/plugin-modernizer-tool).

## What is Modernization Metadata?

Modernization metadata contains information about automated migrations performed on Jenkins plugins using the `plugin-modernizer-tool`. It includes details such as:
- Pull requests created in the target plugin repositories.
- Whether the migration for a given plugin succeeded or failed.
- Whether the pull request made by the plugin-modernizer-tool was merged or not.
- Other migration-related data points.

## Why it's important?
- **Track progress** – Monitor the modernization process, including successful and failed migrations.
- **Identify issues** – Pinpoint recipes that are consistently failing.
- **Measure improvements** – Assess technical debt reduction over time.

## Repository Structure

`plugin-name/reports/`
- Contains **aggregated migrations** for a specific plugin (all migrations applied to that plugin).
- If a plugin has failed migrations, a `failed-migrations.csv` file will be present in this directory.

`plugin-name/modernization-metadata/`
- Contains individual migration records stored as `timestamp.json` files — one per migration.
- Each migration listed here also appears in the aggregated migrations report.

`plugin-name/plugin-info.json`
- Contains **enriched plugin metadata** including all structured dataset fields (see [Dataset Fields](#dataset-fields) below).
- Generated automatically by the [Enrich Plugin Data](.github/workflows/enrich-plugin-data.yml) workflow.

`/reports/ (root-level)`
- Contains **summary reports** for the entire modernization process, including PR statistics, migration statistics, and a list of failed plugins.
- `/reports/recipes/` – Contains a `.json` file for each recipe, detailing its application across different plugins.
- `/reports/plugin-dataset.json` – Combined dataset of enriched metadata for **all** plugins.

`/schema/`
- Contains the JSON Schema definition for the enriched plugin metadata format.

## Dataset Fields

Each `plugin-info.json` file (and every entry in `reports/plugin-dataset.json`) exposes the following structured fields:

| Field | Type | Description |
|-------|------|-------------|
| `pluginName` | `string` | Short identifier of the Jenkins plugin (e.g. `extra-tool-installers`). |
| `pluginRepository` | `string` | URL of the plugin's Git repository. |
| `maintainers` | `array` | List of current plugin maintainers fetched from the [Jenkins Update Center](https://updates.jenkins.io). Each entry contains `id`, `name`, and `email`. |
| `parentPomStatus` | `object` | Status of the plugin's parent POM derived from migration records (`status`, `lastRecipe`, `lastTimestamp`, `pullRequestUrl`, `pullRequestStatus`). Possible `status` values: `upgraded`, `upgrade_failed`, `upgrade_pending`, `unknown`. |
| `deprecatedApiUsage` | `object` | Summary of deprecated API usage and remediation (`hasDeprecatedApis`, `addressedRecipes`, `pendingRecipes`, `lastTimestamp`). |
| `testFrameworkVersion` | `object` | Detected test framework version (`version`: `junit5` / `junit4` / `unknown`) plus migration details. |
| `appliedRecipes` | `array` | Unique IDs of all modernization recipes applied successfully to this plugin. |

### Example `plugin-info.json`

```json
{
  "pluginName": "extra-tool-installers",
  "pluginRepository": "https://github.com/jenkinsci/extra-tool-installers-plugin.git",
  "maintainers": [
    { "id": "ikedam", "name": "Ikedam", "email": "" }
  ],
  "parentPomStatus": {
    "status": "upgraded",
    "lastRecipe": "io.jenkins.tools.pluginmodernizer.UpgradeParent6Version",
    "lastTimestamp": "2026-01-14T10-47-31",
    "pullRequestUrl": "https://github.com/jenkinsci/extra-tool-installers-plugin/pull/184",
    "pullRequestStatus": "merged"
  },
  "deprecatedApiUsage": {
    "hasDeprecatedApis": false,
    "addressedRecipes": [
      "io.jenkins.tools.pluginmodernizer.MigrateCommonsLang2ToLang3AndCommonText"
    ],
    "pendingRecipes": [],
    "lastTimestamp": "2026-01-14T11-46-39"
  },
  "testFrameworkVersion": {
    "version": "unknown",
    "migrationStatus": null,
    "lastMigrationTimestamp": null,
    "pullRequestUrl": "",
    "pullRequestStatus": ""
  },
  "appliedRecipes": [
    "io.jenkins.tools.pluginmodernizer.AutoMergeWorkflows",
    "io.jenkins.tools.pluginmodernizer.MigrateCommonsLang2ToLang3AndCommonText",
    "io.jenkins.tools.pluginmodernizer.UpgradeParent6Version",
    "io.jenkins.tools.pluginmodernizer.UpgradeToRecommendCoreVersion"
  ]
}
```

The JSON Schema for this format is located at [`schema/plugin-info-schema.json`](schema/plugin-info-schema.json).
